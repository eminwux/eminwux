## 🤝 Looking for contributors

If sbsh or kukeon scratches an itch you have, I'd love your help:

- **sbsh** — issues tagged [`good first issue`](https://github.com/eminwux/sbsh/issues?q=is%3Aissue+is%3Aopen+label%3A%22good+first+issue%22) are the easiest entry point. Feedback on the session format is welcome in [Discussions](https://github.com/eminwux/sbsh/discussions).
- **kukeon** — early stage. Design feedback on the agent runtime API is the most valuable contribution right now — [open a discussion](https://github.com/eminwux/kukeon/discussions).
